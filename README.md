## Windows 安装步骤

### 1 打开项目

解压项目文件夹，在文件夹空白处单击右键，选择“通过 Code 打开”，或者在 VS Code 中选择“文件 > 打开文件夹”。

### 2 打开终端

在 VS Code 顶部选择“终端 > 新建终端”。

### 3 创建虚拟环境

在终端中输入：

```powershell
python -m venv .venv
```

如果提示找不到 `python`，尝试：

```powershell
py -m venv .venv
```

### 4 安装依赖（无需激活虚拟环境）

为避免 PowerShell 禁止运行激活脚本，直接输入：

```powershell
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

### 5 配置 DeepSeek 密钥

在 VS Code 左侧找到 `.env.example`，复制一份并将副本改名为 `.env`。打开 `.env`，只在第一行等号后粘贴自己的密钥：

```text
DEEPSEEK_API_KEY=sk-你的真实密钥
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek-flash
```

不要给密钥添加引号或空格，不要把 `.env` 发给别人。

### 6 启动网页

```powershell
.venv\Scripts\python.exe -m streamlit run app.py
```

如果没有自动打开浏览器，请访问：

```text
http://localhost:8501
```

## 完整测试顺序

1. 页面右上角应显示“DeepSeek 与本地知识库已接入”。
2. 在聊天框输入：“我要给七年级学生讲一元一次方程的移项法则，使用人教版，45分钟。”
3. 根据 AI 的追问再回答一至两轮，观察右侧确认单是否自动更新。
4. 进入资料页，检索“移项法则易错点和课堂互动”。
5. 点击“确认资料并生成”，再点击“结合知识库生成第一版教学方案”。
6. 检查 PPT 大纲、教案设计、互动与作业三个标签页。
7. 进入“修改与下载”，输入“增加一道移项易错题，并简化第5页说明”，点击“应用修改”。
8. 分别下载 PPT 课件和 Word 教案，确认文件可以打开。
9. 点击“打开互动小测”，完成答题和自动判分。

本阶段出现任何报错，请发送完整终端错误和页面截图，不要只截最后一行。
